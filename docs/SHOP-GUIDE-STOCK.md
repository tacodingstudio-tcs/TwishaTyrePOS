# Adding tyres and stock — shop guide

A one-page sheet for counter staff. English first, Gujarati below.

---

## English

### 1. A tyre you have never stocked (new size / brand)

**One tyre:** side menu → **Stores** → **Tyres & Items** → **Add Tyre / Item**
Fill in brand, size, sale price (the Data Entry price, GST included), purchase price, and the stock you have now. Save.

**Many tyres at once:** same page → **Import** → choose one:

| You have | Do this |
|---|---|
| An Excel / CSV sheet | **From an Excel / CSV sheet** → pick the file |
| No sheet yet | **Download the Excel template**, fill it, then pick it |
| The supplier's printed bill | **Scan a supplier bill (AI)** → take a photo (needs internet, can be switched off) |

Then: check the table (you can correct any box) → **Check** → **Import**.
"New tyre" = will be created. "Update" = the tyre already exists, so its prices change and the **Stock +** quantity is **added** to what is there.

### 2. More stock of a tyre you already have

| Situation | Where |
|---|---|
| Bought from a supplier | **Stores → Purchase Orders** → Create PO → open it → **Receive Stock** |
| Delivery with no PO | **Stores → Goods Receipts** |
| Many tyres in one go | **Tyres & Items → Import** (Excel or bill photo) |
| Count was wrong / damaged / found | **Stores → Adjustments → New Adjustment** (+ or − with a reason) |

### Don't
- Don't add the same tyre again as a new item. Use Import or a Purchase Order; the app recognises "185/65R15" and "185/65 R15" as the same tyre.
- Don't use *Shop Costs → Tyre / Tube Purchases* to add stock. That records money only.
- Don't import the same sheet twice — the stock is added each time.

### Reorder level
Open the tyre → **Reorder level**. When stock falls to this number it appears in **Stores → Stock Levels → Reorder Alerts**, where you can tick tyres and press **Draft PO**.

## ગુજરાતી

### ૧. નવું ટાયર (જે પહેલાં ક્યારેય રાખ્યું નથી)

**એક ટાયર:** સાઇડ મેનુ → **Stores** → **Tyres & Items** → **Add Tyre / Item**
બ્રાન્ડ, સાઇઝ, વેચાણ ભાવ (Data Entry ભાવ, GST સાથે), ખરીદ ભાવ અને અત્યારે હાથ પર રહેલો સ્ટોક લખો. Save કરો.

**ઘણાં ટાયર એકસાથે:** એ જ પેજ → **Import** → એક રસ્તો પસંદ કરો:

| તમારી પાસે | શું કરવું |
|---|---|
| Excel / CSV ફાઇલ | **From an Excel / CSV sheet** → ફાઇલ પસંદ કરો |
| હજી ફાઇલ નથી | **Download the Excel template** → ભરો → પછી પસંદ કરો |
| સપ્લાયરનું છાપેલું બિલ | **Scan a supplier bill (AI)** → ફોટો પાડો (ઇન્ટરનેટ જોઈએ, બંધ પણ કરી શકાય) |

પછી: ટેબલ તપાસો (કોઈ પણ ખાનું સુધારી શકાય) → **Check** → **Import**.
"New tyre" = નવું બનશે. "Update" = ટાયર પહેલેથી છે, એટલે ભાવ બદલાશે અને **Stock +** ની સંખ્યા હાલના સ્ટોકમાં **ઉમેરાશે**.

### ૨. જે ટાયર પહેલેથી છે તેનો વધુ સ્ટોક

| પરિસ્થિતિ | ક્યાં |
|---|---|
| સપ્લાયર પાસેથી ખરીદી | **Stores → Purchase Orders** → Create PO → ખોલો → **Receive Stock** |
| PO વગર માલ આવ્યો | **Stores → Goods Receipts** |
| ઘણાં ટાયર એકસાથે | **Tyres & Items → Import** (Excel અથવા બિલનો ફોટો) |
| ગણતરી ખોટી / ખરાબ થયું / મળી આવ્યું | **Stores → Adjustments → New Adjustment** (+ અથવા − કારણ સાથે) |

### ન કરવું
- એ જ ટાયર ફરી નવી આઇટમ તરીકે ન ઉમેરો. Import અથવા Purchase Order વાપરો; "185/65R15" અને "185/65 R15" ને એપ એક જ ટાયર ગણે છે.
- સ્ટોક ઉમેરવા માટે *Shop Costs → Tyre / Tube Purchases* ન વાપરો. તે ફક્ત પૈસાનો ખર્ચ નોંધે છે.
- એ જ ફાઇલ બે વાર Import ન કરો — દર વખતે સ્ટોક ઉમેરાય છે.

### Reorder level (ફરી મંગાવવાનું લેવલ)
ટાયર ખોલો → **Reorder level**. સ્ટોક આ સંખ્યા સુધી ઘટે ત્યારે તે **Stores → Stock Levels → Reorder Alerts** માં દેખાય છે; ત્યાં ટાયર પર ટિક કરીને **Draft PO** દબાવો.
